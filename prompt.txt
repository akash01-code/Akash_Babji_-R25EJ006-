----------------------------------------------------------------
REQUEST
----------------------------------------------------------------
Write a 2D graphics editor using * and _.

1. Write functions to draw a circle, rectangle, line, and triangle.
2. You should be able to add objects to the picture, delete objects
   from the picture, and modify objects in the picture.
3. Use a 2D array of characters to store the picture.
4. Write a function to display the picture. Additionally, you can
   use the ncurses package to create menus and draw pictures.

Give me simple and accurate C code to build this mini project.

----------------------------------------------------------------
SOLUTION SUMMARY
----------------------------------------------------------------
A complete C program was written: graphics_editor.c

Key components:
- Canvas: char canvas[30][80] — 2D array of characters
- Shapes: Circle, Rectangle, Line, Triangle
- Characters used: '*' for borders/edges, '_' for fill
- Max 50 objects stored in objects[] array
- ncurses used for interactive menus and display

Drawing algorithms:
- Circle    : Distance formula with 2:1 aspect ratio scaling
- Rectangle : Nested loops with border vs interior check
- Line      : Bresenham's line algorithm
- Triangle  : Scan-fill with sorted vertices + Bresenham edges

Operations supported:
- Add    : prompts user for coordinates, appends to object list
- List   : shows all active objects with ID and parameters
- Delete : soft-delete by setting active = 0
- Modify : marks old entry inactive, reuses slot with new input
- Clear  : resets all objects and canvas

HOW TO USE THE EDITOR
----------------------------------------------------------------
Press 1  ->  Add Circle     (enter centre x, y and radius)
Press 2  ->  Add Rectangle  (enter top-left and bottom-right)
Press 3  ->  Add Line       (enter start and end points)
Press 4  ->  Add Triangle   (enter 3 vertices)
Press 5  ->  List objects
Press 6  ->  Delete object  (by ID number)
Press 7  ->  Modify object
Press 8  ->  Clear canvas
Press q  ->  Quit

Coordinate system:
  Columns : 0 to 79  (left to right)
  Rows    : 0 to 29  (top to bottom)

Example shapes to try:
  Rectangle : x1=5  y1=2  x2=30 y2=12
  Circle    : cx=55 cy=15 radius=7
  Line      : x1=0  y1=0  x2=40 y2=20
